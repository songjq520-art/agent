# 版本是钉死的（==），不要只改数字就升级：mem0 这些库还在快速变，
# 换一个版本号就可能改行为（试跑已经碰到过字段名不存在、接口报错的情况）。
# 升级 = 先在试跑目录重新跑一遍测试，通过了再改这里，
# 再改 memory/mem0_store.py 里对应的版本号常量。
# torch 要走 CPU 专用源：torch==2.15.0+cpu 这个带 +cpu 的版本不在普通 PyPI 上，
# 只能从 PyTorch 自己的 CPU 源下载，所以下面加了 --extra-index-url。
# 安装命令还是同一句：pip install -r requirements.txt（不用加别的参数）。
# 注意：第一次安装要下载约 1.8GB（torch 等大包），还要再从网上下载
# embedding 模型约 96MB，需要一点时间和网络，装一次就行，以后不用重复下载。
